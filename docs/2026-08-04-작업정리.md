## 2. 좌석점유율 계산식 버그 발견 및 수정
- 기존 공식: `총 티켓판매수(totnmrs) ÷ (좌석수 × 공연건수(prfcnt))` → CJ 토월극장 666%, 자유소극장 721% 등 비정상적으로 100% 초과
- KOPIS 공식 통계 페이지(`perfoStatsPerfoByFct.do`)의 실제 값(올림픽공원 KSPO DOME 2025년: 상연횟수 117, 총 티켓판매수 1,151,114)을 우리 캐시 데이터 합산치와 1:1 대조해서 필드 의미를 재확정:
  - `prfdtcnt` → **상연횟수** (기존엔 "공연일수"로 잘못 알고 있었음)
  - `totnmrs` → **총 티켓판매수** (공식 필드, 비공식 추정치가 아니었음)
  - `prfcnt` → 정확한 명칭 불명. 월 단위로 나눠 수집하다 보니 월 경계를 걸친 공연이 이중 집계돼 부정확해서 미사용
- 수정된 공식: `총 티켓판매수 ÷ (좌석수 × 상연횟수)` → CJ 토월극장 50.5%, 자유소극장 71.4%처럼 상식적인 범위로 정상화

## 3. 캘린더가동률 제거
- "연간 실제 가동일수 ÷ 365일" 지표는 KOPIS API가 관(공연장) 단위의 실제 날짜별 데이터를 제공하지 않아 정확히 산정할 방법이 없음을 확인
- `perfoStatsPerfoBy.do`(공연별 순위 통계) 페이지에 공연기간+상연횟수+판매실적이 있어 활용 가능성을 검토했으나, 공개 Open API가 아닌 KOPIS 웹 전용 내부 엔드포인트라 접근 불가로 확인 (boxoffice 엔드포인트도 확인했지만 다른 데이터였음)
- 부정확한 근사치를 보여주는 대신, 캘린더가동률은 **"산정 불가(정보 미제공)"** 로 명확히 표기하고 수치는 완전히 제거 (엑셀/웹페이지 동일 적용)
